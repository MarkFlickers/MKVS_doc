**SCB** (System Control Block) — блок управления системой ядра [[glossary/cortex-m\|Cortex-M]]: отвечает за конфигурацию [[glossary/exception\|исключений]], хранит их приоритеты, флаги ожидания обработки и состояние ошибок, а также адрес [[glossary/isr-vector\|таблицы векторов прерываний]]. ^def-scb

Регистры блока, которые встречаются в лабораторных работах:

| Регистр | Назначение |
| --- | --- |
| `ICSR` | флаги ожидания обработки исключений `NMI`, `PendSV` и `SysTick` |
| `SHCSR` | разрешение и флаги ожидания исключений `MemManageFault`, `BusFault`, `UsageFault` |
| `CCR` | какие ошибки отслеживать: деление на ноль, доступ к невыровненным данным |
| `AIRCR` | поле `PRIGROUP` — [[glossary/priority-grouping\|группировка приоритетов]]; программный сброс МК |
| `SHPR1`–`SHPR3` | приоритеты системных исключений |
| `CFSR` | причина ошибки: поля `MMFSR`, `BFSR` и `UFSR` |
| `MMFAR`, `BFAR` | адрес, обращение по которому вызвало ошибку |
| `VTOR` | адрес таблицы векторов прерываний |
