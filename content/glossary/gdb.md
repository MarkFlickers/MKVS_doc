**GDB** (GNU Debugger) — отладчик, который использует [[glossary/platformio\|PlatformIO]]; он позволяет останавливать программу, выполнять её по шагам и просматривать значения переменных, память, стек и регистры.

Работать с GDB напрямую, вводя команды в консоль отладчика (вкладка
Debug Console), требует знания его системы команд. PlatformIO и [[glossary/vscode\|VS Code]]
предоставляют поверх GDB графический интерфейс, в котором те же действия
выполняются горячими клавишами:

| Клавиши | Действие |
| --- | --- |
| **F5** | запустить отладку или продолжить до следующей точки останова |
| **F10** | Step Over — шаг без захода в вызываемые функции |
| **F11** | Step Into — шаг с заходом в вызываемую функцию |
| **SHIFT+F11** | Step Out — выполнить до возврата из текущей функции |
| **SHIFT+F5** | завершить отладку |

В режиме отладки появляются окна Variables (переменные), Watch (выражения
пользователя), Call Stack (стек вызовов), Breakpoints ([[glossary/breakpoint\|точки останова]]), а для
работы с микроконтроллером — Disassembly (машинные инструкции), Registers
(регистры процессора), Peripherals (регистры периферийных блоков) и Memory
(содержимое памяти).
