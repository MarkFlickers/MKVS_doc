**FPU** (Floating Point Unit) — блок операций с плавающей точкой: сопроцессор, который выполняет сложение, умножение, деление и извлечение корня над вещественными числами аппаратно, за единицы тактов вместо десятков и сотен у программной эмуляции.

Ядро [[glossary/cortex-m\|Cortex-M7]] микроконтроллера [[glossary/stm32h745\|STM32H745]]
содержит блок FPv5 с двойной точностью, ядро Cortex-M4 — FPv4 с одинарной. Блок добавляет к
регистрам процессора собственный набор `S0`–`S31`, который операционной системе приходится
сохранять при [[glossary/context-switch\|переключении контекста]].

Компилятору о блоке сообщают два ключа: `-mfpu` задаёт его архитектуру (например,
`fpv5-sp-d16` — FPv5 только для одинарной точности), а `-mfloat-abi` — соглашение о вызовах:
`soft` полностью эмулирует вещественную арифметику, `softfp` использует блок, но передаёт
аргументы через регистры общего назначения, `hard` передаёт их через регистры самого FPU.
Объектные файлы, собранные с разными значениями `-mfloat-abi`, скомпоновать вместе нельзя.
