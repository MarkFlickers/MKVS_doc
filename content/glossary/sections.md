**Секции** — именованные части исполняемого файла, каждая со своим назначением и своим местом в памяти микроконтроллера. ^def-sections

Секции, которые встречаются в [[glossary/linker-script\|скрипте компоновщика]]:

| Секция | Что содержит | Где размещается |
| --- | --- | --- |
| `.isr_vector` | таблица векторов прерываний | начало FLASH (адрес 0) |
| `.text` | машинный код функций | FLASH |
| `.rodata` | константные данные | FLASH |
| `.data` | инициализированные переменные | RAM, значения хранятся во FLASH |
| `.bss` | переменные, инициализируемые нулём | RAM |

Кроме них определяются служебные секции:

- `.ARM.extab` и `.ARM.exidx` — данные для механизма исключений C++
  (ARM EHABI, Exception Handling Application Binary Interface);
- `.preinit_array`, `.init_array`, `.fini_array` — массивы указателей на
  функции, вызываемые до, во время инициализации и при завершении программы;
  через этот механизм вызываются конструкторы статических объектов C++;
- `.ARM.attributes` — метаданные о сборке, в микроконтроллер не записываются.
