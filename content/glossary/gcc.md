**GCC** (GNU Compiler Collection) — свободный набор компиляторов; для микроконтроллеров [[glossary/cortex-m\|Cortex-M]] применяется его сборка `arm-none-eabi-gcc`, а для программ [[glossary/host-target\|хост-компьютера]] — обычный `gcc`.

Сборка программы на C складывается из нескольких шагов, и все они
запускаются через драйвер `gcc`:

1. **препроцессор** (`cpp`) — раскрывает `#include` и макросы;
2. **компилятор** (`cc1`) — переводит текст на C в ассемблерный код;
3. **ассемблер** (`as`) — получает объектный файл `.o`;
4. **[[glossary/linker\|компоновщик]]** (`ld`) — собирает объектные файлы и библиотеки в [[glossary/elf\|ELF-файл]].

Полезные ключи, которые встречаются в лабораторных работах:

- `-std=c11` — стандарт языка;
- `-Wall -Wextra` — наиболее полный набор предупреждений; хорошая практика —
  собирать программы именно с ними;
- `-O0`, `-Os` — уровень оптимизации (без оптимизации, по размеру);
- `-g` — включить отладочную информацию;
- `-D ИМЯ` — задать макроопределение;
- `-I путь` — добавить каталог поиска заголовочных файлов.
