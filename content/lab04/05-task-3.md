Задание со звёздочкой: выполняется по желанию и приносит дополнительные баллы.

Добавьте в рабочее приложение независимый [[glossary/iwdg\|сторожевой таймер IWDG]].

1. Ознакомьтесь с документацией на IWDG — раздел [48 Independent watchdog (IWDG)](docs/rm0399-stm32h745.pdf#page=2047) документа RM0399 [3].

2. Рассчитайте делитель IWDG и период обновления так, чтобы таймер срабатывал после 3–5 секунд отсутствия активности.

3. Добавьте в проект драйвер LL/IWDG.

4. С помощью библиотеки [[glossary/hal-ll\|LL]] включите и инициализируйте сторожевой таймер.

5. В суперцикле программы обеспечьте сброс счётчика таймера с рассчитанным периодом.

6. Для проверки работы IWDG добавьте в меню CLI пункт, который запускает задачу, не возвращающую управление планировщику (вечный цикл). Убедитесь, что IWDG перезагружает процессор.
