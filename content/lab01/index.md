## Введение

Процесс разработки программного обеспечения (ПО) для микроконтроллеров и встраиваемых систем включает множество технологических операций: редактирование кода, компиляцию и компоновку объектных файлов для создания библиотек или исполняемых бинарных артефактов, запись программ в память микроконтроллера, анализ программного кода, тестирование, отладку и др. Для выполнения и автоматизации перечисленных действий используют интегрированные среды разработки (IDE — Integrated Development Environment), например «Keil uVision», «Mbed Studio», «STM32CubeIDE» (только для STM32).

Цель настоящей лабораторной работы — освоить процесс разработки программного обеспечения с использованием [[glossary/platformio\|PlatformIO]] и [[glossary/vscode\|Visual Studio Code]]. Полученные знания и практические навыки будут использованы при выполнении последующих практических заданий.

Visual Studio Code – это специализированный текстовый редактор с поддержкой большого числа языков программирования и функциональных расширений. Одним из таких расширений является PlatformIO – среда разработки, объединяющая различные инструменты для создания программ для микроконтроллеров. Помимо редактора и компилятора PlatformIO и VS Code предоставляют такие инструменты, как отладчик, средства автоматизированного тестирования кода, [[glossary/static-analysis\|статический анализатор]] и монитор (текстовый терминал для взаимодействия с [[glossary/host-target\|целевым устройством]], на котором выполняется разработанная программа).

PlatformIO и VS Code – это свободно распространяемые кроссплатформенные продукты, которые могут быть установлены на компьютеры под управлением Windows, macOS или Linux. С их помощью можно разрабатывать программы как для настольных компьютеров, так и для микроконтроллеров различных семейств, например Atmel AVR, Espressif 32 и ST STM32.

## Цель работы

Изучить возможности и получить практические навыки применения инструментов PlatformIO + VS Code для разработки программного обеспечения:

- создавать и конфигурировать проекты PlatformIO;
- редактировать код и собирать его в исполняемый файл;
- создавать и подключать программные библиотеки;
- создавать модульные тесты и выполнять тестирование;
- применять отладчик;
- применять инструменты [[glossary/static-analysis\|статического анализа]] кода.

В архиве:

> [!note] О текстах правил
> В `misra-rules.txt` лежат формулировки из MISRA C:2023 — это консолидированная
> редакция MISRA C:2012 вместе с поправками. Нумерация правил в обеих редакциях
> одна и та же, поэтому найденное анализатором правило ищется в
> [MISRA C:2012 Guidelines](docs/misra-c-2012-guidelines.pdf) по его номеру.
