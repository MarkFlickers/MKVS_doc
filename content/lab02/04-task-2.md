Определите, к каким выводам подключены красный и зелёный светодиоды отладочной платы (документация находится в папке DOCS).

Библиотека для управления красным, жёлтым и зелёным светодиодами должна иметь следующий программный интерфейс:

<div class="mkvs-retype">

```c
typedef enum {
    led_green = 1,
    led_yellow = 2,
    led_red = 4,
    led_all = 1|2|4
} led_t;

void led_enable(led_t led);  // включает тактирование блока GPIO
void led_toggle(led_t led);
void led_on(led_t led);
void led_off(led_t led);
void led_disable(led_t led); // переводит вывод в режим Analog
```

</div>

**Задание выполняется парами.**

Первый студент самостоятельно реализует функции библиотеки на языке C или C++.

Второй студент самостоятельно разрабатывает юнит-тесты для библиотеки. Тесты должны проверять функции включения, выключения и переключения для светодиодов всех цветов.

Совместно необходимо добиться прохождения всех созданных тестов для разработанной библиотеки.

## Дополнительные баллы*

Дополнительные баллы ставятся за выполнение дополнительного задания во время защиты.

Также дополнительные баллы предоставляются за «качество» кода, в том числе за следование принципам DRY и KISS в программном решении.

> [!note] Важное примечание
> **DRY** — это принцип разработки программного обеспечения, призванный минимизировать дублирование информации в коде. Согласно DRY, «каждая единица знания должна иметь единственное, непротиворечивое и авторитетное представление в рамках системы». На практике это значит, что повторяющиеся части кода должны объединяться в общие функции или модули.
>
> Принцип **KISS** («Keep It Simple, Stupid» или «Keep It Short and Simple») в разработке ПО определяет «простоту» как одну из ключевых целей и требует избегать использования более сложных средств, чем необходимо.

Для решаемой задачи одним из критериев может являться количество изменений, которое потребуется внести в код при добавлении в библиотеку поддержки ещё одного светодиода или ещё одной функции.
